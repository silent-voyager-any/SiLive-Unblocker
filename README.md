# Unblur Current Tab

A small Chrome extension that removes CSS blur effects from every tab on a website after you enable it once.

## Install

1. Open `chrome://extensions` in Chrome.
2. Enable **Developer mode**.
3. Click **Load unpacked**.
4. Select this folder.
5. Pin **Unblur Current Tab** to the toolbar if desired.

Click the extension icon while viewing a page, then approve Chrome's request to access that website. The extension immediately applies to matching tabs that are already open and automatically runs in new tabs and pages on the same website.

Permission is requested only for the specific website you enable. The setting persists across browser restarts and can be removed from the extension's site-access settings in Chrome.

Chrome does not permit extensions to run on internal pages such as `chrome://settings` or the Chrome Web Store.
